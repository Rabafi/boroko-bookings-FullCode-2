Offline & Sync

Built for lodges where internet is unreliable.

Works without internet

Every operation — bookings, payments, POS, inventory — works offline. No waiting for connectivity.

Automatic sync

Changes queue locally and sync via Supabase RPCs when connection returns. Financial operations are prioritised.

Multi-desk LAN sync

Multiple front-desk computers sync over local network. No internet required. Conflict detection prevents double-bookings.

Cache freshness

The system knows which data may be stale. Staff see freshness indicators so they can make informed decisions.

Predefined roles

Staff lifecycle

In-app messaging
