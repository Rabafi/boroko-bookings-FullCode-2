Quick answers

Questions a prospect may still have before sending the enquiry.

Can we start with Starter and move later?

Yes. The package structure is built to support that path naturally.

Do you need a website backend for this form?

No. This version is static and simple on purpose. It uses email as the lead path.

What if we want online reservations too?

That is where Pro becomes most attractive, because it includes the branded reservations page and broader commercial tools.

Can Boroko work for a smaller lodge?

Yes. Boroko is especially good for properties that need structure without enterprise complexity.

What do we actually test in the free 7-day demo?

You can test the everyday parts of the product that matter most to your lodge, like bookings, rooms, invoices, and the package level that fits you best.

What if we are not sure which package fits us?

That is normal. The first conversation is meant to help match your lodge to the right package based on rooms, workflow, and whether you have a bar or kitchen.

Do we need to be very technical to use Boroko?

No. The whole point is to make the system easier to understand for real lodge teams, not harder.
