## Tsa Bonno LodgingOS 1.5.5

### Highlights

- Introduces the new Tsa Bonno LodgingOS name, logos, and Windows installer presentation.
- Preserves the existing Boroko Bookings application identity, local data, and update channel for in-place upgrades.
- Keeps the untested Food & Beverage workspace hidden until its operator workflows complete release testing.
- Includes the latest LodgingOS stability, operational, and compatibility improvements.

### Operator notes

- Install this update over the existing Boroko Bookings or Tsa Bonno LodgingOS installation.
- Existing profiles, settings, offline work, and local application data should remain available after the update.
- Restart the desktop application after the download completes to apply the update.
- This Windows installer is currently unsigned and may show an Unknown publisher or Microsoft Defender SmartScreen warning.
